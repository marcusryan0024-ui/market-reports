# Recaps

Daily and weekly trading recap notes.

## Files

- `YYYY-MM-DD.md` — daily recap, Monday through Thursday
- `YYYY-MM-DD-weekly.md` — Sunday weekly rollup

## Daily recap structure

Each daily file records four things:

1. **Called** — what the morning report flagged as setups, with the levels
2. **Happened** — what those names actually did
3. **Traded** — what was actually taken, entry/exit, result
4. **Notes** — the read, what worked, what to change

The value is in section 1 vs section 2. Because the morning report commits to specific
setups and levels *before* the open, the recap can score them honestly afterward rather
than reconstructing a story. Over time that produces a real hit rate on the catalyst
calls, not a vibe.

## Sunday weekly rollup

Rolls up Monday through Thursday: setups called vs hit, trades taken, P&L, and the
themes that repeated. Feeds the win-rate strip on the landing page and informs the
next week's catalyst map.

## Rules

- Outcomes are recorded from real data (quotes, fills, P&L), never estimated. A blank
  is better than a guess.
- A setup that was called but not traded still gets scored — that's how missed-profit
  gaps get caught.
- Losses and misses get the same detail as wins.
